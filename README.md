# 💰 Finanzas SMS

**Aplicación Android para la gestión de finanzas personales mediante mensajes SMS bancarios.**

Finanzas SMS es un proyecto académico desarrollado para facilitar el seguimiento de movimientos financieros y fomentar una mejor administración del dinero desde un dispositivo Android.

## 📱 Funcionalidades

- **Inicio:** acceso a las principales secciones de la aplicación.
- **Perfil:** sección de información del usuario.
- **Comprobantes:** consulta y organización de comprobantes.
- **Mis finanzas:** visualización de movimientos financieros y gráficos.
- **Educación financiera:** contenidos para aprender a administrar mejor el dinero.
- **Herramientas:** calculadoras de ahorro y préstamos.

## 🛠️ Tecnologías utilizadas

- Kotlin
- Android Studio
- Android SDK
- XML
- Gradle
- Git y GitHub

## 📥 Instalación

1. Accede a la sección **Releases** de este repositorio cuando esté disponible.
2. Descarga el archivo APK de Finanzas SMS.
3. Abre el archivo en un dispositivo Android compatible.
4. Autoriza la instalación desde esa fuente si Android lo solicita.
5. Abre la aplicación y concede únicamente los permisos necesarios para utilizar sus funcionalidades.

**Nota:** La aplicación está diseñada para Android. Algunas funcionalidades relacionadas con SMS requieren permisos específicos del sistema.

## 🔐 Privacidad

Los mensajes bancarios pueden contener información financiera sensible. Se recomienda utilizar la aplicación únicamente en dispositivos de confianza y revisar los permisos solicitados.

## 👨‍💻 Desarrollo

Proyecto académico desarrollado en equipo, con implementación e integración de funcionalidades de la aplicación y una contribución inicial de un compañero al módulo de lectura de SMS.

Este proyecto busca aplicar conocimientos de desarrollo de aplicaciones móviles y ofrecer herramientas prácticas para mejorar la educación y organización financiera.
